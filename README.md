# 鋼の経営 — WELD WORKS

スマートフォン・PCで遊べる、2D見下ろし型の溶接会社経営シミュレーション。

## プレイ
公開URL: https://kou114w.github.io/welding-company/

1. 受注市場から鉄骨案件を受注。
2. 従業員・対応設備・材料等級・作業方針を選んで生産開始。
3. 翌営業日へ進めて製造。品質検査後、納品または再加工。
4. 毎月の給与・賃料・保守・返済を見込み、利益で会社を成長。

求人・面接・採用、給与設定・昇給・賞与、研修・資格、人事評価・退職、設備故障と整備、材料在庫、研究、工場増築、銀行融資、決算、品質による報酬・満足度・評判・継続注文を実装。

長期契約は初回＋追加2回の依頼。高満足度では継続発注。品質は技能・設備性能・設備状態・材料・資格・研究・工場環境・疲労・作業方針から計算し、品質乱数は使いません。設備故障は日次確率です。

目標は評判90、累計決算利益1,000万円、工場Lv.3。達成後も自由経営が可能。現預金マイナスで倒産します。

## 保存と対応機種
Safari / Chrome 等のモダンブラウザ。iPhone・Android向けレスポンシブWebゲーム（ネイティブアプリではありません）。端末内 localStorage に自動保存。クラウド同期なし。ガイドからJSONバックアップの書出し・読込みが可能。

## 開発
Node.js 22以上。実行時の外部JS依存なし。

```sh
npm test
npm start
```

http://localhost:4173 を開く。`dist/` がそのまま公開用ファイルです。`engine.js` はUIと分離した経営ロジック、`app.js` は日本語UI。GitHub Actionsでテスト後GitHub Pagesにデプロイします。

## モデルの簡略化
価格・年利4.5%・税率20%・資格区分はゲーム内設定。30日を1か月とし、設備・増築費を即時費用化する簡略会計です。元金返済・融資は損益に含めません。人員・設備の同時使用は1案件まで。工場配置は設備数による自動レイアウトです。実際の会計や溶接作業の指導を目的としていません。
